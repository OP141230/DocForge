feat: Phase 4 - Knowledge Base & Source-Based Document Generation

Implemented comprehensive knowledge base system with file upload, text extraction,
full-text search, and source-based document generation (RAG).

## Major Features

### Knowledge Base System
- File upload with 6 format support (PDF, DOCX, TXT, MD, HTML, CSV)
- Text extraction using pypdf2 and beautifulsoup4
- Smart chunking with configurable size and overlap
- SQLite FTS5 full-text search across content
- User-isolated storage with security

### Source-Based Generation (RAG)
- Attach reference files to document briefs
- Retrieval service searches relevant chunks
- AI generates content using uploaded sources
- Source citations in document metadata
- Maintains context from user's own documents

### Backend Implementation
- 4 new services: storage, extraction, chunking, retrieval
- 4 new repositories for knowledge base entities
- 5 new database tables with FTS5 index
- Migration script for Phase 4 schema
- Source-aware generation in Groq provider

### Frontend Implementation
- Knowledge Base page with file management UI
- Drag-and-drop file uploader with progress
- File preview modal showing extracted content
- Multi-select file attachment in brief wizard
- Search and filter across uploaded files

### Developer Experience
- Fixed .env loading in start_backend.ps1
- Updated to use available Groq model (openai/gpt-oss-120b)
- Improved error handling and validation
- Comprehensive testing and verification

## Technical Details

**Database**:
- knowledge_files: file metadata
- extracted_content: full extracted text
- content_chunks: searchable segments
- content_chunks_fts: FTS5 virtual table
- brief_file_attachments: many-to-many links

**API Endpoints**:
- POST /api/knowledge/upload
- GET /api/knowledge/files
- GET /api/knowledge/files/{id}
- DELETE /api/knowledge/files/{id}
- GET /api/knowledge/files/{id}/content
- GET /api/knowledge/search

**Dependencies Added**:
- pypdf2: PDF text extraction
- beautifulsoup4: HTML parsing
- lxml: XML/HTML processing
- python-multipart: file upload support
- pydantic-settings: config management
- email-validator: user validation
